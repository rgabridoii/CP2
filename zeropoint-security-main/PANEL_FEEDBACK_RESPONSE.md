# Suggested response to the UX feedback

> We agree with the feedback that our first prototype was visually organized but still assumed that users already understood cybersecurity terminology. Since our target stakeholders can include computer-shop owners and IT generalists, we revised the UX so the system guides the user instead of only presenting technical controls. We reorganized the navigation around user goals, added a beginner workflow, renamed technical labels in plain language, marked a recommended scan for first-time users, added explanations for CVE, CVSS, severity and scanner findings, and moved technical controls under Advanced sections. The underlying OpenVAS and Greenbone functionality remains available, but the user does not need to understand those components before completing a basic vulnerability scan.

## If asked why the technical terms are still present

> We did not remove the technical information because it is still important for IT and security users. Instead, we use progressive disclosure: simple wording and recommended defaults are shown first, while technical names and advanced settings remain available for users who need deeper control.
