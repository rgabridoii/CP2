🛡 ZeroPoint Security

A vulnerability management platform with AI-assisted remediation guidance

Mapúa Malayan Digital College Group 9 · Section S3102 MO-IT200D1 Capstone 1 Adviser: Rhimshie Jay Aquino
What is it?

ZeroPoint Security is a fully containerized, self-hosted vulnerability management platform that scans network assets using Greenbone/OpenVAS, then uses a local AI model (Llama 3.2 via Ollama) to prioritize findings and generate actionable remediation guidance through retrieval-augmented generation (RAG). The system recommends and tracks remediation actions. It does not automatically apply patches or configuration changes.

Who is it for?

Philippine SMEs, specifically local computer and IT-service shops that lack the budget for enterprise vulnerability management solutions or a full-time security specialist. The platform gives them an accessible, free, and self-hosted way to discover and address security vulnerabilities in their infrastructure.

Development objectives (5)
  • Web dashboard with role-based access control
  • OpenVAS integration for authenticated & unauthenticated scanning
  • Centralized vulnerability finding aggregation
  • AI-assisted remediation guidance via RAG
  • Fully Dockerized one-command deployment
Research objectives (3)
  • Measure detection accuracy using ground-truth evaluation (precision, recall, F1)
  • Evaluate AI-generated guidance for correctness and safety via expert review
  • Assess platform usability through formative testing (SUS questionnaire)
Technology stack
FastAPI 0.115 Python 3.12 React 18 Vite Greenbone CE / OpenVAS python-gvm 27.2 Ollama + Llama 3.2:3b Docker Compose (~14 services) PostgreSQL Redis

🔒 All AI inference runs fully offline. No data leaves the host machine. Deployable on both Linux and Windows (Docker Desktop + WSL2). Compliant with RA 10173 (Data Privacy Act) data residency requirements.

Current status

Working prototype (v0.4.1). Oral defense completed with the panel issuing 15 recommendations requiring major revision. All 15 points have been addressed in the revised manuscript. Reference audit and figure finalization are in progress for final resubmission.
